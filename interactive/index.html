The model. Toij = ui (RB)oj with loss ½‖T − T*‖², the population loss for whitened inputs. With one u per output the only change is ui → Uoi, so any gap between the solid and dashed curves comes from sharing.

The computation. Your browser integrates exact gradient flow on all 10 or 12 parameters with adaptive Runge-Kutta, so there is no step size that could cause an overshoot by itself. Aligned start: rk = bk = δ, u = (√2δ, 0). Random start: independent normal entries with standard deviation δ. Checked against the offline runs behind the post: at target (1, 0.5) and δ = 0.01 both give a 1.72% overshoot, and the weaker entry reaches half its target at t = 86 with shared u and t = 198 with one u per output.
