# Does the easier root contrast teach a feature that the harder one needs?

**Status.** This is a proposed CPU study. The existing `toy_checks.json` checks selected algebra and ODE predictions, and `grammar_audit.json` contains the top-rule spectra for the three depth-four grammars. The four-arm planted sweep, checkpoint readout study, and selective-gradient intervention below are pending. They require new drivers. The execution agent can run the CPU study when asked.

The planted problem asks whether the weakly aligned right child must learn a feature separately when the two child tables are untied. The depth-four problem asks a different question. Given one root contrast with substantial additive signal and another with weak additive signal, does passing the former's gradient into the lower cores accelerate fitting the latter? The random grammars have no purely interactive label contrast, so accelerated learning in the second problem would demonstrate help from that particular contrast, without establishing strict necessity.

## 1. Planted task with an exact population loss

Use the four-class two-level grammar in [the tied derivation](../../../notes/child-feature-enabling/toy.tex) and [the untied derivation](../../../notes/child-feature-enabling/untied.tex). All 256 strings are equiprobable. Encode the root as the two signs $(U,UV)$ and expose only root targets. The predictions are $b h_L$ and $w h_Lh_R$. Minimize half the sum of squared errors with targets $(sU,UV)$.

Cross tied versus untied child tables with $s=1$ versus $s=0$. All arms start with $b=w=0$, unit-norm child tables and positive alignment $\delta$ to the planted sign. Take $\delta$ in $\{0.08,0.04,0.02,0.01,0.005\}$. An independent full-table reference can use $h=\delta H+\sqrt{1-\delta^2}N$, where $N$ is obtained from a Gaussian Walsh-coefficient vector generated with CPU Torch seed 21, projected off $H$ and normalized in the uniform-pair inner product. Give both untied copies the same starting table as the tied arm. Unit rates apply in the orthonormal coefficient coordinates. In the tied arm sum the gradient contributions from both occurrences of $h$. No statistical error bars attach to these deterministic trajectories.

Implement the four ODEs with the parameter flow in the note, using CPU float64 and SciPy `solve_ivp(method="Radau", rtol=2e-11, atol=2e-13)`. Reuse the tied and untied reference checks in `toy_check.py`; extend the untied driver to cover $s=0$, arbitrary seed alignment, and the right-child crossing. At $\delta=0.08$, compare both table gradients and both readout gradients with direct differentiation of the 256-row loss before proceeding. Use generic nonzero readouts and unequal untied tables for this check, so it tests both gradient paths. Rerun the smallest $\delta$ with tolerances reduced by a factor of four and record the change in each event time. For each trajectory stop after all events or $t=4/\delta^2+300$, whichever comes first.

Write $r_i=\mathbb E[h_iH_i]/\sqrt{\mathbb E[h_i^2]}$, $H_L=U,H_R=V$. At each event and at 200 common logarithmically spaced times up to the final recorded time, save $r_L,r_R,b,w$, the actual hard fit $D_h=1-\mathbb E[(UV-wh_Lh_R)^2]$, and the frozen-child ceiling $A_h=r_L^2r_R^2$. Save first upward crossings of $r_L=1/2$, $r_R=1/2$, and $D_h=1/2$, using ODE event interpolation. A ceiling below $1/2$ rules out a fitted root reaching $1/2$ with those children. A ceiling above $1/2$ allows a lag due to the readout.

**Discriminating figure.** Plot the interval from left-child half alignment to hard half fit against $\log(1/\delta)$, with tied and untied trajectories on the same axes for $s=1$. The tied theorem predicts a bounded interval. Untying predicts slope $1/\lambda_2$, where $\phi=(1+\sqrt5)/2$ and $\lambda_2=(\sqrt{\phi^2+4\phi}-\phi)/2$. Show adjacent-point slopes and the predicted value. On a separate panel plot $\delta^2 T_h$ against $\delta$ for $s=0$, with reference limits $1/4$ (tied) and $1/2$ (untied). At one common $\delta$, overlay $D_h(t)$ and $A_h(t)$ to show when a gap reflects a slow readout. Compare full-table and reduced trajectories at identical finite alignment and solver tolerance. Compare the asymptotic slopes across shrinking alignments; the bounded remainder permits a finite-alignment mismatch even with exact integration.

## 2. Read out existing depth-four checkpoints

Use the aligned, untied, identity-initialized `rhm-dynamics` root runs with width 16, $n=v=16,m=4,L=4$, grammar seeds 0, 1, 2 and model seeds 0, 1, 2. The run directory convention is `root_m4_g{g}_r16_s{i}/ckpt_{step}.pt`. The Git repository contains summaries; point the driver at the original checkpoint archive. Check the path against the selected run, then verify the stored configuration and step when reading it with `studies.rhm.common.load(path, device="cpu")`. Record a missing checkpoint as missing. Aggregate loss curves cannot recover its child representations.

Select the two contrasts from each grammar's **top rule table alone**, before inspecting any learning curves. Reuse the construction in `grammar_audit.audit`. On the 64 ordered legal rules let $E$ encode the root label, $X$ encode the two child symbols as concatenated one-hots, $P_X=XX^\dagger$, and let $H$ have orthonormal columns spanning centered label vectors. Set $Q=EH/\sqrt m$, diagonalize $Q^\top P_XQ$, and use $c_e=\sqrt n H v_{\max}$ and $c_h=\sqrt n H v_{\min}$. The two contrasts have mean zero and unit variance under the uniform root law. Save their actual vectors, both neighboring eigenvalue gaps, and the value of each additive fraction. Fix each sign by making its largest-magnitude entry positive (lowest index on a tie). For eigenvalues within $10^{-10}$ of an extremum, project the centered class indicator vectors in class order onto its eigenspace and normalize the first projection of norm above $10^{-10}$. These choices are different for each grammar but identical across all its models and arms. Here “easy” refers to additive predictability from the true child symbols. Its learning speed remains an observable.

At saved updates $0,50,100,150,200,300,400,500,700,1000,1500,3000,10000,20000,40000$, evaluate the following quantities for each available file.

- Generate its fixed rules with `common.rules(cfg["grammar"])`. Call `root_moments(model,rules)` once and `regression_oracle(moments,c)` for each contrast. Record $A_c=1-\min_w\mathbb E[(c_Y-w^\top Z)^2]$, the numerical Gram rank, and the eigenvalue cutoff used. Repeat the oracle at ten times its default relative cutoff; report the change. $A_h$ measures accessible variance at that checkpoint. An invertible child basis change preserves its exact value while changing Euclidean gradient magnitudes.
- On the original unmodified classifier report sample cross-entropy in nats and accuracy on the fixed diagnostic trees returned by `common.diag_trees` and inputs from `common.task_batch`. Use the same 20,000-tree diagnostic set for every checkpoint of one grammar, and reserve `common.test_trees` for final held-out measurements, with forward passes in batches of 512. Optionally compare CE with the deterministic `losses.ce_bracket(model,rules,reveal=1)` and retain both endpoints. Sample CE estimates and deterministic bounds have different interpretations.

**Discriminating figure.** Against the original Adam update, plot exact $A_h,A_e$ together in one panel and held-out CE in a second panel with the same horizontal axis. Show trajectories for each initialization within each grammar. An initially large $A_h$ followed by a late CE improvement favors readout or optimization delay over a missing hard feature as measured by this oracle. A late rise of $A_h$ motivates the intervention below. A snapshot correlation alone does not identify what drove the lower cores.

## 3. Intervene on the easy gradient in a paired two-head run

Use the same nine grammar/init combinations and the stored initial lower weights (step 0) for both arms. If that file is absent, rebuild once with `common.build` from the documented identity-init configuration, clone the state into both arms, and record that provenance separately. The matched pair remains valid for the intervention. Later CE checkpoints are observational only. Initialize two fresh bias-free vectors $w_e,w_h\in\mathbb R^{256}$ to zero. Discard the categorical root from the optimizer. Obtain $Z$ from the top two bonds returned by `TreeTN(..., acts=True)`, flattening their outer product in left-right order.

Train both arms on the same two-output loss $\tfrac12\mathbb E[(w_e^\top Z-c_e(Y))^2+(w_h^\top Z-c_h(Y))^2]$. In the intact arm differentiate both terms through $Z$. In the detached arm use $w_e^\top\operatorname{stopgrad}(Z)$ for the first prediction; leave the hard prediction and both readout updates intact. No forward prediction changes simply because of the detach. Use plain SGD, no momentum, weight decay, gradient clipping or schedule, in CPU float64, to isolate how easy supervision reaches the lower cores. Duplication of heads and summed (not output-averaged) loss must be the same in both arms.

Use batches of 256 online trees for up to 4,000 updates per arm. Set the CPU generator seed to $7{,}000{,}400+1000g+i$ using grammar seed $g$ and initialization seed $i$. Generate each batch **once** with `grammar.sample_trees` and pass it to both arms at that update. Before the study, pilot both arms at grammar 0 and a separate initialization seed 9 for 300 updates at each constant rate in $\{10^{-4},3\times10^{-4},10^{-3}\}$. Among rates whose pilot remains finite with both total population losses below 10 at every 25-step evaluation, select the rate with the smallest mean final hard MSE across the two arms, breaking ties toward the smaller rate. If none qualifies, report the failed pilot and stop. Freeze that one rate for the nine pairs. The estimand concerns this two-target regression optimizer and horizon; the original CE/Adam trajectories provide a separate reference.

At step 0 and every 25 updates save exact $A_h$ and the trained hard fit
$D_h=2w_h^\top b_h-w_h^\top Fw_h$, where $b_h=D^\top c_h/n$, $D$ is the matrix of class-conditional feature means and $F$ is the product-feature Gram from `root_moments`. Record the easy counterparts, both lower-gradient norms, and $D_h\le A_h$ within reported numerical tolerance. Gradient norms at each evaluation are from the same current batch in both arms (use the next training batch, with no extra sampling); compute the *pre-detach* gradients of the two loss terms separately for that diagnostic. At the final step omit those norms if there is no next batch. First check the implementation with identical cloned parameters, nonzero test heads and one common batch: easy and hard predictions and both head gradients coincide, and the difference in the full lower update direction equals the easy loss gradient. This distinguishes a path intervention from dropping a label or freezing a model.

**Primary endpoint.** For each arm let $T$ be its first scheduled evaluation with $D_h\ge1/2$, and retain both bracketing evaluations. Compare the two arms within each pair and show all nine pairs. A positive $T_{\rm detached}-T_{\rm intact}$ means intact training reached the observed threshold sooner. For censored arms report $T>4000$ and the corresponding paired bound when possible. As an all-pair summary report the difference of capped first-detection times $\min(T,4000)$, calling it a restricted difference and giving counts of censored arms. If both arms miss the threshold this difference is zero by construction and says nothing about their ordering after 4,000 updates. A nonfinite run is an optimization failure reported separately, never a censored crossing. No test of generalization across random grammars is planned from three grammars.

**Discriminating figure.** Show per-pair intact and detached hard fits against the same update axis, together with their matching frozen-child ceilings. In a second panel connect the two half-fit times within each pair and mark censoring with arrows. Earlier $A_h$ and $D_h$ in the intact arm support faster acquisition of a representation useful for this target. Earlier $D_h$ with similar $A_h$ means the attainable hard fit alone does not account for the gap. Readout conditioning and the history of a changing representation are both possible explanations. Equal or reversed times remain a valid result. A faster intact arm establishes a causal effect of that easy-gradient path in this protocol; it cannot show that the unmodified depth-four classifier requires this exact path.

## Amendments made during execution (2026-11-25)

The three sections above are the plan as handed off. These changes were made while running it. Each says what was known when it was made.

**A1, planted sweep (section 1).** Each trajectory is integrated 15 time units past its last event, so the overlay of $D_h$ and $A_h$ shows saturation. The event times come from the integration before that point and are unaffected. The independent full-table reference was integrated for all twenty arm-seed combinations.

**A2, checkpoint readout (section 2).** One column is added: $D_c^{\rm CE}=1-\frac1N\sum_x\big(c_{y}-\sum_j p_j(x)c_j\big)^2$ on the 20,000 diagnostic trees, the fit of the unmodified classifier's posterior-mean prediction of contrast $c$. The plan had the oracle $A_c$ and the cross-entropy but no fit of the trained predictor to the two contrasts. $D_c^{\rm CE}$ is a sample estimate from a different predictor class (softmax of a trilinear root), so it is not bounded by $A_c$.

**A3, extended intervention (section 3).** The protocol as written is run first and reported whatever it gives (`results/intervention/`). Its pilot rates are too small for its horizon: on the pilot pair (grammar 0, init seed 9) the hard mean squared error after 300 updates was 0.99996 or more at all three rates, and 4,000 updates at $10^{-3}$ is a gradient-flow time of 4. Exploratory runs on the same pilot pair, at rates 0.01 to 1 for 4,000 updates, showed the hard fit moving only at rates of 0.1 and above. No evaluation pair had been run at any rate when this amendment was written. The extended protocol changes three numbers and nothing else:

- pilot rates $\{0.01,0.03,0.1,0.3,1\}$ in place of $\{10^{-4},3\times10^{-4},10^{-3}\}$;
- pilot length 4,000 updates in place of 300, since 300 updates cannot rank these rates either;
- horizon 40,000 updates per arm in place of 4,000, so that a delayed arm can still cross.

The eligibility and selection rules, the pilot pair, the nine evaluation pairs, their step-0 weights and batch streams, the loss, plain SGD, the evaluation schedule and the endpoint are unchanged. Results go to `results/intervention-extended/`. Its censoring bound is $T>40{,}000$.

**A4, rate sensitivity.** Minibatch SGD at these rates need not follow gradient flow, so the ordering of the two arms is checked at a second rate: 0.1, one half-decade below the extended pilot's choice if that choice is 0.3, for 40,000 updates on the three pairs with init seed 0 (one per grammar). Results go to `results/intervention-extended-lr0.1/`. This is a robustness check on the sign and rough size of the effect, with three pairs.
